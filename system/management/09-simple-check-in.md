# Короткая сверка шести задач — ответ простыми словами

Эта памятка помогает обновить рабочий статус без таблиц и специальных знаний. Можно ответить в личном чате короткими словами. В GitHub не вставлять заполненные ответы, имена, контакты, резюме, договоры, точные платежные документы или ключи.

Для любого пункта допустимый ответ: **«не знаю»**, **«не помню»** или **«пока не готова решать»**. Это честный статус, а не ошибка.

## 1. Карта управления
Подходит ли описанная карта ролей вашей работе сейчас?
- подходит;
- нужно поправить (напишите только название роли/функции);
- не знаю.

## 2. Единый реестр проектов
Изменилось ли что-нибудь в активных проектах после последнего среза?
- нет;
- да (название проекта и что изменилось — без личных данных);
- не знаю.

Если есть текущие вакансии P08, можно написать только ID V01–V07 и короткий этап: **активна / пауза / закрыта / не знаю**. Срок и следующий шаг можно добавить, только если они точно известны. ФИО кандидатов, заказчиков и любые контакты не присылать.

## 3. Ресурсы
Можно указать примерные итоги, если они под рукой; документы и скриншоты не нужны.
- сколько часов в неделю реально доступно на развитие продаж: число или «не знаю»;
- были ли расходы на сервисы/рекламу за последний полный месяц: «да / нет / не знаю»; сумму указывать необязательно;
- какие каналы сейчас доступны: Avito / HH / Telegram / LinkedIn / другое / не знаю.

Не прикладывайте счета, выписки, логины и платёжные данные.

## 4. Приоритеты
Есть ли подтверждённые ближайшие сроки или обязательства, которые нужно поставить выше остальных задач?
- нет известных;
- есть (проект и дата, если точно известна);
- не знаю.

Если времени на исполнение задачи не измеряли, так и написать — число не придумывать.

## 5. 30-дневный цикл привлечения
Запускать ли бесплатный тест обращений к потенциальным B2B-клиентам?
- пока нет;
- да, начать с даты __;
- сначала подготовить черновик для моего просмотра.

Отправка сообщений, публикации, платные объявления и подписки требуют отдельного конкретного поручения. Ответ «да» в этой анкете сам по себе не разрешает платные действия.

## 6. Первая услуга
Какую гипотезу исследовать дальше?
- подбор сотрудников для прямых компаний (B2B);
- консультация по безопасности предприятия (P12);
- другое направление;
- пока не выбирать.

Цена, гарантии и обещания клиентам остаются неутверждёнными, пока вы их отдельно не зададите.

## Как ответить
Можно скопировать только нужные строки и написать после двоеточия. Пропущенные пункты останутся со статусом **«не подтверждено»**. Я перенесу в публичный GitHub лишь обезличенные сводные статусы после отдельной проверки; ваши ответы и клиентские подробности туда не копируются.
