# 06-AUTO-003 · Диспетчер (подготовлено, НЕ развёрнуто)

Это независимый исполняемый код в **отдельной ветке**, а не подтверждённая рабочая
автоматизация. Он не изменяет основной API или существующий планировщик.

## Реализованные элементы

- Приватные SQL-таблицы очереди и журнала резервирования бюджета
  (`migrations/06_auto_003_brain_ops.sql`). **Миграция применена к основной Supabase 28.11.2026 и проверена.**
- Приём задач с уникальным `source_key` и маршрутизацией `--role auto`.
  Неизвестные темы направляются Штабу, а не случайному исполнителю.
- Атомарный захват поручения, запрет повторного платного исполнения при
  сетевой неопределённости, хранение результата и response ID.
- Два официальных способа исполнения: Responses API (самостоятельный текстовый
  исполнитель) и Agents API (сохранённый Platform-агент по `BRAIN_AGENT_ID`).
  В режиме Agents API инструменты и субагенты выключены для безопасности,
  удалённый session ID сохраняется, результаты считываются отдельно.
- Отдельный вызов роли Матушки-гусыни для письменной ревизии.
  Он не заменяет независимого человека и не утверждает решение собственника.
- Бюджетный затвор на дневной объём и одну операцию. Цены задаются вручную
  после сверки тарифов конкретной модели. Это предохранитель, **не
  безусловная гарантия против превышения счета провайдера**.
- Запуск по умолчанию выключен. Нет фонового цикла или публикации API наружу.

## Конфигурация (показана только схема, секреты не коммитить)

```ini
# /etc/kartashova/dispatcher.env, chmod 600 — ПОКА НЕ ВКЛЮЧАТЬ
BRAIN_DISPATCH_ENABLED=0
BRAIN_EXECUTION_BACKEND=managed # managed для сохранённого агента; responses — отдельная альтернатива
BRAIN_AGENT_ID=             # реальный ID агента из OpenAI Platform
BRAIN_OPENAI_MODEL=         # доступная модель для расчёта/проверки
BRAIN_DAILY_BUDGET_USD=    # утверждённый дневной бюджет в долларах
BRAIN_MAX_CALL_USD=        # максимум резервирования на вызов
BRAIN_INPUT_USD_PER_MILLION=  # документированная цена входящих токенов
BRAIN_OUTPUT_USD_PER_MILLION= # документированная цена исходящих токенов
BRAIN_MAX_OUTPUT_TOKENS=1200
BRAIN_MAX_RUNNING=1
```

Передавать `OPENAI_API_KEY` и `CORPORATE_BRAIN_DATABASE_URL` через уже
существующие защищённые файлы `EnvironmentFile`; не выводить их командой
`env`, в журналах или переписке.

## Команды после ревью, миграции и утверждения бюджета

```bash
cd /opt/kartashova/symmetrical-guide/system/runtime
# Локальная регистрация поручения БЕЗ API-вызова; только доверенная консоль:
.venv/bin/python -m corporate_brain.dispatcher --enqueue \
  --project P-001 --role auto --source-key P001-REAL-001 \
  --instruction 'Исследовать потребность аудитории в сервисе Что на ужин?'
# Разовый запуск исполнителя + проверки, если BRAIN_DISPATCH_ENABLED=1:
.venv/bin/python -m corporate_brain.dispatcher --once
```

Каждый запуск `--once` сперва опрашивает сохранённую сессию, затем
может взять новое задание и передать готовое заключение Матушке-гусыне.
Проверка независима как отдельный вызов с инструкцией ревизора, но
не является независимой организационной приёмкой.

Для постоянного исполнения можно создать отдельный приватный systemd
timer, который вызывает `--once`, но **в PR он не включён**.
Сначала необходима приёмка, чтобы не получить неконтролируемую платную
очередь и конфликт со старой автоматизацией.

## Решение собственника 28.11.2026

Собственник согласовал **только один** контролируемый пробный прогон с
плановым верхним бюджетом **$0.30**. В код добавлен предохранитель:
`BRAIN_MAX_TOTAL_TASKS=1` (иное значение отвергается), дневной лимит
не более $0.30, полное резервирование лимита сохранённой сессии до вызова.
Для пробного прогона задавать `BRAIN_MAX_CALL_USD=0.10`, оставив резерв
для отдельной ревизии. Ограничение API `spend_control.limit` — best-effort,
не абсолютный финансовый стоп.

Тариф GPT-6 Luna на 28.11.2026 по официальной документации:
$0.10 за 1 млн входящих и $0.50 за 1 млн выходных текстовых токенов.
Цена считается оценочно, другие виды расхода и возможные тарифные
коэффициенты/хостинг проверять отдельно. Установить
`BRAIN_INPUT_USD_PER_MILLION=0.10`,
`BRAIN_OUTPUT_USD_PER_MILLION=0.50`,
`BRAIN_OPENAI_MODEL=gpt-6-luna` только после подтверждения, что
сохранённый агент действительно использует эту модель.

CI-проверка без платных API добавлена в
`.github/workflows/dispatcher-offline.yml`. Факт успешного завершения
проверок пока не подтверждён. Без тестов релиз запрещён.
