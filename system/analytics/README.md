# Аналитика портфеля и готовность данных

## Что можно применить уже сейчас

Реестр проектов, решений, задач, исследований и фактического дохода находится в CSV/SQLite. Для текущего объёма данных тяжёлая BI-система добавит настройку, но не даст новых рыночных фактов. Поэтому начальный инструмент — read-only аудит на стандартной библиотеке Python:

```bash
python system/analytics/readiness.py
```

Чтобы сохранить снимок аудита:

```bash
python system/analytics/readiness.py --output system/analytics/portfolio-readiness.md
```

Скрипт не подключается к аккаунтам и не меняет реестры. Он считает заполненность, показывает отсутствие данных в воронке/доходах, список недостающих аналитических входов и приоритет продуктовой мастерской. Пустая таблица трактуется как «не занесено в систему», а не как доказательство нулевой активности.

Последний сформированный снимок — [готовность портфельной аналитики](portfolio-readiness.md).

## Ресурс GitHub

Официальный [OpenAI Agents SDK](../automation/openai-agents-sdk.md) уже скачан в `/workspace/openai-agents-python`. В его документации проверены схемы «менеджер + узкие специалисты», handoff, структурированные результаты, трассировка и верификатор для исследовательского отчёта. Для будущего отдельного приложения это может помочь автоматизировать последовательность «исследование → анализ покупателя → критическая проверка → сводка».

Сейчас SDK не запускается и не соединяет разные GPT Projects с Perplexity. Для живой оркестрации нужны программная интеграция с доступными API, разрешённые источники данных, ключи в защищённом хранилище, оценка стоимости, логирование и человеческое подтверждение коммерческих/внешних действий. Поэтому использовать его позже имеет смысл после того, как повторяющийся ручной процесс измерен.

## Что нужно собрать для реальной аналитики

- Воронка по каналам: подходящие компании/запросы, источник, дата, этап, предложение, причина отказа и оплата.
- Денежные факты: предложенная и согласованная сумма, поступление, прямые расходы, налоги, выплаты партнёрам, часы и чистый результат.
- Показатели маркетинга: публикации/каналы, дата, аудитория, содержательные обращения, встречи, предложения и оплаты.
- Для каждого внешнего вывода: URL/файл, дата, география, точная цитата/цифра и ограничение источника.
- Для продукта: проблема покупателя, подтверждение спроса, стоимость теста, фактический результат и решение владелицы.

## Границы GitHub

Исходный репозиторий `akartashova51180-code/symmetrical-guide` имеет настроенный локальный remote, но локальная ветка пока без коммитов, а у origin не вернулись опубликованные ссылки. Текущие рабочие файлы существуют в этой среде; считать их уже сохранёнными в GitHub нельзя. Поиск репозиториев через обычный GitHub API заблокирован сетевым прокси (403), тогда как клонированный OpenAI SDK доступен локально. Не загружать случайные библиотеки; выбирать ресурс под подтверждённый расчёт/процесс.
