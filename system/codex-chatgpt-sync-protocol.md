# Обязательный протокол взаимодействия Codex ↔ ChatGPT
Дата решения: 2026-10-27. Владелица: Анастасия Карташова.

## Цель
Все проекты и принятые решения должны иметь одну проверяемую актуальную версию. Codex и ChatGPT должны использовать общий источник, не требуя от владелицы повторного изложения решений.

## Реальные ограничения
GitHub даёт доступ к файлам, но не к полным историям чужих чатов. Автоматическая межчатовая синхронизация пока НЕ настроена; создание файла не означает её запуск. Не обещать мгновенной передачи и не называть неувиденный документ полученным.

## Порядок работы
1. Источник версий и обмена: этот репозиторий, далее — защищённая база событий. Все проекты из system/projects.csv входят в охват, не только продюсерский центр.
2. Каждое утверждённое решение — отдельная запись: event_id, project_id, created_at (с timezone), source (Codex или ChatGPT), источник/ссылка, тип (решение/задача/факт/гипотеза), текст, версия, затронутые проекты, утверждение владелицы, статус доставки. Повторы по ID и версии не создавать.
3. Перед работой проверять последнюю доступную версию решений; после работы публиковать новое принятое решение через доступный механизм и проверять чтением, что запись появилась. Если запись не удалась — честно обозначить статус.
4. Codex отвечает за техническую реализацию и фиксацию архитектурных изменений; ChatGPT — за координацию, контекст и анализ. Оба не вправе самостоятельно менять решения владелицы, цены, расходы или ставить на запуск приостановленные проекты.
5. Конфликт версий фиксировать, не перетирать содержимое. Личные данные, тексты закрытых договоров, резюме и ключи доступа НЕ выкладывать в публичный репозиторий.

## Первая задача реализации
Создать двусторонний защищённый транспорт событий: источник изменений → очередь/webhook → авторизованная база → подтверждение доставки, проверка дублей и ошибки. Провести тест Codex → база → ChatGPT и ChatGPT → база → Codex. Пока чтение истории чатов через официальный интерфейс не доступно, синхронизировать именно опубликованные структурированные решения и файлы, не все реплики.
