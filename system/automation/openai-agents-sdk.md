# Референс для автономной координации: OpenAI Agents SDK

Проверенный и скачанный официальный репозиторий: [/workspace/openai-agents-python](/workspace/openai-agents-python). Git revision: `0dc4cf152bff1f50bdc0e41f28808563406545b2`. Лицензия репозитория — MIT. Документация проекта указывает Python 3.10+ и переменную `OPENAI_API_KEY` для запуска.

## Зачем он подходит

SDK содержит базовые механизмы построения специализированных агентов, передачи задач между ними (handoffs/agents as tools), инструментов и MCP, человеческих подтверждений, сессий/контекста и трассировки выполнения. Это может стать программной основой для отдельного приложения, где секретарь координирует маркетолога, рекрутера, Home Office и студийные роли.

## Чего скачивание не делает

- Не подключает существующие GPT Projects и не читает их чаты автоматически.
- Не включает календарь, почту, соцсети, Avito/HeadHunter, CRM и мессенджеры без отдельных источников/коннекторов.
- Не запускается фоном и не присылает сводки без сервера, планировщика и безопасного хранилища.
- Не создаёт готовых агентских инструкций для этой корпорации: текущие инструкции нужно перенести и связать с инструментами.
- Не даёт ChatGPT-сеансу новые постоянные полномочия; это библиотека для разработанного приложения.

## Следующий технический маршрут

1. Спроектировать минимальный сервис: общий реестр проектов/задач/решений/вакансий, аудит действий и права по ролям.
2. Перенести в него инструкции секретаря и агентов; начать с чтения локальных данных и черновых рекомендаций.
3. Добавить утверждённый планировщик для запуска утренней сводки и календарных напоминаний.
4. Подключать источники по одному, с read-only доступом и проверкой пользы.
5. Включать публикации, внешние сообщения, расходы и бронирования только отдельными действиями после явного подтверждения владелицы.

Ключ API и зависимости не устанавливали, агент-сервис не запускали. Перед следующим этапом нужны отдельное решение о среде запуска, источнике истины, допустимых подключениях, бюджете API/хостинга и правилах подтверждения действий.
